# Toy Block — Fusion 360 Practice

## Objective

Create a 3D toy block with top studs, a hollow underside, and bottom support columns while learning the fundamentals of parametric modelling in Fusion 360.

## Skills Learned

### 1. Fusion 360 Fundamentals
- Understanding the difference between part design and assembly design
- Configuring default preferences and units in millimeters (mm)
- Changing the units of an individual design file
- Navigating the workspace using zoom, pan, and orbit
- Creating projects and folders, and saving designs

### 2. Sketching and Solid Modelling
- Creating 2D sketches
- Using sketch constraints
- Converting 2D sketches into 3D geometry using Extrude
- Creating and positioning features to build a complete model

### 3. Patterning and Feature Modelling
- Creating studs on the top of the toy block
- Using Solid Rectangular Pattern to replicate features
- Understanding why a solid feature pattern can be preferable to a sketch pattern
- Hollowing out the model using Shell
- Sketching and creating the bottom center columns
- Applying Fillet to round selected edges

## Design Features

The completed model includes:

- A rectangular toy block body
- Repeated studs on the top surface
- A hollowed underside
- Bottom center columns
- Rounded edges created using fillets

## Files

- `toy-block.f3d` — Native Fusion 360 design file, including the editable modelling history

## Status

Completed beginner CAD modelling exercise.

The model has been created digitally. Physical manufacturing and testing have not yet been performed.

## Key Takeaway

This exercise introduced the fundamentals of sketch-based modelling, feature patterns, shell operations, fillets, and an organized Fusion 360 workflow. These concepts will serve as a foundation for designing mechanical components and robotic hardware in future projects.
