# Compliant Wheel — Fusion 360 Practice

## Objective

Design a compliant wheel for a robotics application using Autodesk Fusion 360. Practise sketching, projections, constraints, extrusion, circular patterns, components, and solid-body editing while exploring a wheel design intended for flexible 3D printing with TPU (thermoplastic polyurethane).

## Skills Learned

### 1. Sketching and Geometry
- Creating the initial wheel sketch
- Projecting existing geometry into sketches
- Applying sketch constraints to maintain geometric relationships
- Building a structured sketch for a patterned wheel design

### 2. Solid Modelling
- Using the Extrude tool to create 3D geometry
- Applying Circular Pattern to repeat features around an axis
- Understanding how repeated features can form a compliant wheel structure

### 3. Components and Design Organization
- Understanding components in Fusion 360
- Creating and inserting components
- Organizing model geometry into reusable design elements

### 4. Solid Editing and Inspection
- Using the Combine tool to join or modify solid bodies
- Using Offset Face to adjust existing geometry
- Inspecting the model using Fusion 360's Inspect tools

### 5. Visual Refinement
- Applying appearances to improve the model's presentation
- Reviewing the overall wheel geometry and its individual features

## Design Features

The model represents a compliant wheel concept for robotics. Its geometry is designed to provide flexibility through the structure of the wheel rather than relying only on a rigid solid wheel body.

The exercise demonstrates how sketch constraints, repeated features, components, and solid modelling operations can be combined to create a more complex mechanical part.

## Potential Robotics Application

Compliant wheels can be useful in mobile robotics applications where flexibility and deformation may help with contact over uneven surfaces. The actual performance depends on the geometry, material, print orientation, infill, and operating loads.

TPU is a potential material for prototyping flexible wheel designs because of its elasticity. However, the completed CAD model still requires physical testing to evaluate grip, deformation, durability, and load capacity.
