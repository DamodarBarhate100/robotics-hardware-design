# Autonomous Robot Chassis — Fusion 360 Sketch Practice

## Objective

Practise 2D sketching and geometric constraints by designing the outline of an autonomous robot chassis. Explore different sketch tools and learn how construction geometry, patterns, mirroring, and constraints help create organized and editable designs.

## Skills Learned

### 1. Sketch Geometry
- Creating line segments
- Using different rectangle and circle tools
- Creating splines and arcs
- Drawing polygons and ellipses
- Creating slot geometries
- Adding text to sketches

### 2. Sketch Editing Tools
- Applying rectangular and circular sketch patterns
- Using sketch fillets to round corners
- Creating offset geometry
- Trimming unwanted sketch geometry
- Understanding different geometry selection types

### 3. Construction Geometry and Constraints
- Converting sketch geometry into construction lines
- Understanding the difference between regular sketch geometry and construction geometry
- Modifying sketch constraints
- Using the Mirror tool to create symmetrical geometry
- Organizing geometry using reference lines and constraints

### 4. Practical Application — Robot Chassis
- Applying sketch tools to create a robot chassis outline
- Positioning geometric features for a mobile robot design
- Using construction geometry to support accurate placement
- Applying symmetry and repeated patterns where appropriate

## Design Focus

This exercise applies fundamental sketching techniques to a mobile robot chassis concept. The emphasis is on learning the tools and methods required to create accurate, editable 2D geometry.

The sketch can serve as a starting point for a 3D chassis model. Before manufacturing, the design would need appropriate dimensions, material and thickness specifications, mounting-hole locations, and manufacturing clearances.

This exercise introduced a broader range of sketch tools, construction geometry, constraints, patterns, offsets, trimming, and mirroring. These techniques form the foundation for creating dimensionally accurate mechanical parts and progressing toward functional robotics hardware.
