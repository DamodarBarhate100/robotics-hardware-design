# Glass Bottle — Fusion 360 Practice

## Objective

Create a 3D bottle in Autodesk Fusion 360 using a reference image, sketch constraints, spline curves, and the Revolve feature. Practise refining the model using Shell, Fillet, and visual appearances.

## Skills Learned

### 1. Design Setup and Reference Images
- Starting a new design using Part Design
- Inserting a reference image into a Fusion 360 design
- Calibrating a reference image to match real-world dimensions

### 2. Sketching and Constraints
- Sketching half of a bottle's profile
- Using Fit Point Spline to create curved geometry
- Applying Coincident constraints to connect sketch elements
- Understanding the difference between centerlines and construction lines

### 3. 3D Modelling
- Using Revolve to create a 3D bottle from a 2D profile
- Understanding how the sketch profile and axis of revolution define the resulting solid
- Using Shell to hollow out the bottle
- Troubleshooting a common Shell operation error
- Applying Fillet to the top and bottom edges

### 4. Design Refinement
- Reordering features in the Fusion 360 timeline
- Changing the visual style of the model
- Applying realistic appearances to improve the model's presentation

## Design Features

The completed model represents a bottle created from a reference image. The model uses a revolved profile to form its main shape, with curved geometry, rounded edges, and a hollow interior.
