# Flapper Wheel — Fusion 360 Practice

## Objective

Design a boot kicker, also known as a flapper wheel, in Autodesk Fusion 360. Practise construction planes, sketch geometry, extrusion, Sweep, Pipe, and pattern features to create a mechanical component intended for 3D printing.

## Skills Learned

### 1. Components and Sketching
- Inserting components into a Fusion 360 design
- Creating a cylinder sketch
- Applying horizontal constraints
- Sketching finger or flapper features
- Using Intersect to reference existing geometry

### 2. Construction Planes
- Creating a tangent construction plane
- Understanding how construction planes provide suitable sketching surfaces for curved or angled geometry
- Positioning sketches relative to existing model geometry

### 3. Solid Modelling
- Using Two-Side Extrude to extend geometry in both directions
- Applying the Sweep tool to create geometry along a path
- Creating repeated features using Rectangular Pattern
- Combining solid bodies using Combine
- Applying Fillet to round selected edges

### 4. Advanced Features and Repetition
- Using Circular Pattern to distribute features around an axis
- Creating geometry with the Pipe tool
- Applying repeated circular patterns to build up the wheel structure
- Organizing the model using components

### 5. Appearance and Presentation
- Applying appearances to distinguish model surfaces and improve visualization

## Design Features

The model represents a boot kicker or flapper wheel concept built from a central cylindrical structure and repeated projecting features.

The exercise combines sketching, construction geometry, solid modelling, and pattern operations to create a more complex mechanical shape from individual features.

## Potential Robotics Application

Flapper wheels can be explored in mobile robotics for applications involving contact with irregular surfaces or obstacles. Their practical performance depends on the geometry, material, dimensions, mounting arrangement, and operating conditions.

The model is a CAD practice design. Its suitability for a particular robot application must be evaluated through design analysis and physical testing.
