# Mounting Bracket — Fusion 360 Practice

## Objective

Create a 3D mounting bracket in Autodesk Fusion 360 while learning the fundamental workflow of sketch-based modelling, parametric design, and feature replication.

The exercise focuses on creating dimensioned sketches, converting them into solid geometry, adding holes, and using rectangular patterns to create repeated features efficiently.

## Skills Learned

### 1. CAD Workflow and Design Planning
- Understanding the basic part-design workflow
- Planning a part before modelling
- Understanding how sketches and solid features work together

### 2. Sketching and Parametric Modelling
- Creating 2D sketches
- Applying sketch dimensions
- Using sketch constraints to control geometry
- Understanding parametric modelling and the design timeline
- Editing dimensions to make designs adaptable

### 3. 3D Solid Modelling
- Using Extrude to convert 2D sketches into 3D geometry
- Creating holes using sketches
- Building a bracket through multiple modelling operations
- Understanding how features depend on their underlying sketches

### 4. Feature Patterns
- Using Rectangular Pattern to replicate features
- Understanding pattern direction, spacing, and quantity
- Creating angled rectangular patterns
- Reducing repetitive modelling work by reusing existing features

## Design Features

The mounting bracket is modelled using sketches and extruded solid geometry. Sketch dimensions and constraints control the geometry, while rectangular patterns are used to replicate selected features.

The resulting model demonstrates basic bracket geometry and a parametric workflow that can be adapted to other mechanical components.

## Key Takeaways

This exercise introduced the relationship between sketches, dimensions, constraints, and solid features in parametric CAD. It also demonstrated how rectangular patterns can simplify the creation of repeated geometry.

These techniques form a foundation for designing functional robotics hardware, including sensor brackets, motor mounts, electronics supports, and chassis components.
