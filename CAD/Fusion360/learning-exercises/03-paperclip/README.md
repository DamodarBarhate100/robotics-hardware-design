# Paperclip — Fusion 360 Practice

## Objective

Create a 3D paperclip in Autodesk Fusion 360 using sketch geometry and the Sweep feature. Learn how to construct a well-defined path, create a profile, and generate a solid model by sweeping the profile along the path.

## Skills Learned

### 1. Design Setup
- Setting up a new Part Design file
- Understanding the role of sketches and features in solid modelling

### 2. Sketching and Constraints
- Creating a path using the Line tool
- Understanding automatic sketch constraints
- Fully defining a sketch using dimensions and constraints
- Converting regular geometry into construction geometry
- Using the Tangent Arc tool to create smooth curved paths
- Using origin points and following good practices when sketching paths
- Naming sketches clearly for parametric modelling

### 3. Sweep Feature
- Understanding the difference between a sweep profile and a sweep path
- Creating the paperclip path
- Sketching the profile on the XZ plane
- Applying the Solid Sweep command to create 3D geometry
- Understanding chain selection when selecting a sweep path
- Understanding the Sweep Distance parameter and its range from 0 to 1

## Design Features

The paperclip is modelled using a continuous path and a sketch profile. The Sweep feature follows the selected path to generate the 3D solid geometry.

This exercise demonstrates how curved paths can be used to create wire-like components and other mechanical shapes.

## Key Takeaways

This exercise introduced path-based modelling using Sweep, sketch constraints, construction geometry, tangent arcs, and parametric sketch organization. These concepts are useful for designing wire forms, handles, cable guides, curved brackets, and other mechanical components in robotics.
